### 🔎 Overview

FTPChat is a lightweight, Python‑based encrypted messaging protocol that uses FTP servers as the backbone for communication. It’s designed for **legacy environments** and **resource‑constrained systems** such as low‑power routers with USB/FTP support, making it ideal for discreet or offline operations.

### ✨ Key Features (v2.1)

- End‑to‑end encryption (PBKDF2‑SHA256 → Fernet) with zlib compression

- FTP/FTPS/SFTP fallback for compatibility

- Threaded send/receive with auto‑refresh loop

- Offset/line‑count syncing to reduce bandwidth

- Saved setups with per‑setup notification ignore

- Tray minimization for background use

- Modern **CustomTkinter GUI** with scrollable chat history

### ⚙️ Protocol Operation

Messages are exchanged via a shared text file on the FTP server. Each entry includes:

- Timestamp (YYYY‑MM‑DD HH:MM)

- Username

- Encrypted payload (Base64‑encoded, compressed, salted)

Supports conflict‑safe writing, compression, and offset‑based reading for efficiency.

```

pip install cryptography customtkinter paramiko plyer pystray Pillow

```

### 🖥️ Usage

1. Prepare FTP server (local or cloud)

2. Run `FtpChat.exe` (Windows) or `python FtpChat.py` (Mac/Linux)

3. Configure connection (host, credentials, chat file, encryption key)

4. Start chatting – messages auto‑sync across clients

### 📌 Deployment Scenarios

- Local LAN team communication

- Global cloud access via [SFTPCloud](https://sftpcloud.io/tools/free-ftp-server)

- Legacy hardware (routers with FTP)

- Offline operations (sync when connected)

Tlock – Text Locker Encryption Protocol

**License:** Custom Proprietary (MIT‑style, commercial use requires permission)

### 🔎 Overview

Tlock is a simple yet powerful desktop encryption tool for protecting text, files, and code. It supports custom formats (`.tetf`, `.tlock`, `.tpy`, `.tjs`) and integrates with IDEs for secure project handling.

### ✨ Key Features

- Encrypt/decrypt text files (`.tetf`)

- Protect any file (`.tlock`)

- Secure Python/JavaScript projects (`.tpy`, `.tjs`)

- Built‑in IDE support for encrypted code

- Speech tools (speech‑to‑text, text‑to‑speech)

- Compression for smaller outputs

### 📥 Installation

- **Portable:** Download `tlock.exe` (no install required)

- **Setup:** Install via `tlock.exe` setup build

### 🖥️ Usage

- Save protected text → `.tetf`

- Encrypt/decrypt files → `.tlock`

- Secure code projects → `.tpy` / `.tjs`

### 📂 Supported File Types

| Extension | Purpose |

| --------- | ---------------------- |

| `.tetf` | Protected text |

| `.tlock` | Protected binary files |

| `.tpy` | Protected Python |

| `.tjs` | Protected JavaScript |
